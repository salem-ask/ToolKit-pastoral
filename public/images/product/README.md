# Product image

This folder contains the official poster / mockup for **The Complete
Pastor's Toolkit** pack, translated into English from the original French
artwork:

```
pack-mockup.jpg
```

(edit `images.productMockup` in `src/config/product.ts` to change the
file).

This image is used:
- in the Hero (first section);
- in the "Your pastoral library, all in one place" section;
- as the Open Graph image for sharing on Facebook / WhatsApp.

As long as a file referenced in `product.ts` isn't present here, a clearly
labeled placeholder is shown instead (no visual is fabricated).
